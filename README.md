# Agent Toolkit

Reusable tools for working with local project files.

[PresentStage](presentstage/README.md) turns a slide deck and speaker notes into an offline HTML presentation or a standalone macOS app. It opens separate windows for the audience and the speaker.

Keep slide decks, media and exported files in the project that owns them. See [AGENTS.md](AGENTS.md) for the checks to run before committing.
